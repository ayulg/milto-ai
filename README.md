# Milto AI - Career Guidance System

An adaptive AI-powered career exploration system for Ethiopian universities.

## Features
- 120-question assessment
- 10-level career matching
- Career analysis
- Personal development
- AI Coach

## Quick Start

### Backend
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py

### Frontend
cd frontend
npm install
npm run dev
